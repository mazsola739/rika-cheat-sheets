# Képek

Saját agy-kép a beépített (kódból rajzolt) illusztráció helyett:

1. Tedd ide a fájlt, pl. `brain.webp`.
2. Az `assets/js/common.js` elején írd be az útvonalát: `const ART_IMAGE = 'assets/img/brain.webp';`

Ezután a kezdőlapon és az oldalfejlécekben ez a kép jelenik meg. A roadmap oldalon a kép a haladással
együtt színeződik ki (0%-nál szürke, 100%-nál teljes színű).

Ajánlott: széles, kb. 3:1 arányú kép, világos vagy átlátszó háttérrel, legalább 1600 px szélesen.
Csak olyan képet tegyél ki, amihez megvan a jogod (saját, AI-val készített vagy licencelt stockkép).

---

Drop an image here (e.g. `brain.webp`) and set `const ART_IMAGE = 'assets/img/brain.webp';` at the top
of `assets/js/common.js`; the site then uses it instead of the built-in drawn illustration. On the roadmap page it turns from grey to full color as you progress.
Only use an image you have the rights to.
